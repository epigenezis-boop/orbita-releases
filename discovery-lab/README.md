# Orbita Discovery Lab 0.1

Экспериментальная ветка от Orbita 1.8.0. Стабильный пакет и release.json не изменяются. Цель: проверить качество и доступность открытых источников музыкальных рекомендаций до встраивания в Electron.

## Первый запуск (Windows PowerShell)

Требуются Node.js 18+ и curl.exe (обычно входит в Windows 11). Из корня экспериментальной ветки:

```powershell
$env:ORBITA_DISCOVERY_PROXY = 'http://127.0.0.1:10809'
node .\discovery-lab\listenbrainz-probe.mjs "Nightwish" medium 12 nightwish.json
```

Переменная прокси необязательна; указывайте только действующий адрес вашего локального прокси. Без неё curl использует стандартные настройки окружения. Если LB Radio требует авторизацию (401/403), получите бесплатный пользовательский токен в https://listenbrainz.org/settings/ и задайте его только локально:

```powershell
$secret = Read-Host "ListenBrainz token" -AsSecureString
$env:LISTENBRAINZ_TOKEN = [System.Net.NetworkCredential]::new('', $secret).Password
node .\discovery-lab\listenbrainz-probe.mjs "Nightwish" medium 12 nightwish.json
Remove-Item Env:LISTENBRAINZ_TOKEN
```

Не коммитьте токен, отчёты с личными данными и пользовательский профиль. Стенд не отправляет историю прослушиваний и не изменяет аккаунты. Токен передаётся только ListenBrainz, не MusicBrainz.

Аргументы: исполнитель (точное имя либо MBID), режим easy/medium/hard, число кандидатов 1–30, путь JSON. При неоднозначном имени используйте MBID. Запросы последовательные, пауза не менее 1,1 секунды между началами; при HTTP 429 стенд прекращает работу.

## Что проверяем

- Поиск исполнителя в MusicBrainz и запрос LB Radio.
- Удаление дубликатов по Recording MBID, ограничение повторов исполнителя посредством round-robin.
- Обогащение названиями, ISRC, длительностью и списком изданий.
- Ручная оценка музыкального соответствия. Listen count — популярность, не коэффициент сходства.
- Доступность записей в Звуке пока не проверяется. Издания в отчёте — варианты, а не гарантированно оригинальные альбомы.

Источники: https://listenbrainz.readthedocs.io/en/latest/users/api/core.html ; https://musicbrainz.org/doc/MusicBrainz_API .

## Следующий этап

1. Реальный сетевой прогон для нескольких любимых исполнителей. Проверить доступность API, ответ LB Radio и полноту метаданных.
2. Сопоставление кандидатов с каталогом Звука через существующий клиент Orbita; проверка версий, доступности, дубликатов.
3. Локальный граф SQLite, источники и достоверность связей, импорт коллекции только по метаданным, история событий и инкрементальное обновление.
4. Независимые стратегии треков и альбомов; ползунок доли незнакомых записей, сохранение оригинального порядка альбомов.
5. Интеграция в Electron через отдельный адаптер. Добровольная отправка прослушиваний только после явного включения; хранение токена защищённо. Кэш, лимиты, отмена, обработка недоступности сервисов.
6. Classic и новый интерфейс используют один движок. Никаких обязательных LLM или платных API.

До проверки живых API и сопоставления со Звуком не выпускать обновление и не изменять стабильную сборку.
