## Orbita 1.7.2 — настроение и навигация

- В «Моём потоке» вместо числовых полей — поле настроения с точкой: энергичное, весёлое, грустное, спокойное. Работают перетаскивание, касание и стрелки клавиатуры. Выбор сохраняется. Для применения нажми кнопку запуска потока; само перемещение точки не перезапускает музыку.
- У солнца больше нет прямых прорезей. Его волнообразные разрывы и передний план используют общую геометрию и движутся согласованно.
- «Локальная библиотека» переименована в «Библиотека ПК».
- «Плейлисты» оформлены как «Моя музыка» и по умолчанию свёрнуты. Состояние раскрытия запоминается.
- Основные вкладки получили единый набор цветных SVG-значков.
- Сохранены русский и английский языки, все четыре темы, выравнивание громкости и обновления без прав администратора.
- Новые тестовые примеры обезличены. Добавлена проверка публикации на файлы профиля и сигнатуры секретов.

Проверено локально: 110 модульных тестов и браузерные сценарии четырёх тем, двух языков, поля настроения, истории очереди, настроек и виджета. Браузерные проверки используют моделируемый сервис; реальный подбор музыки в аккаунте Звука из среды разработки не запускался. Существующий протокол energy/fun сохранён. Интерфейс использует диапазоны 0–1.5 и 0–2 соответственно; точное соответствие границам тюнера на сайте Звука не подтверждено.

## English
A draggable mood pad replaces the numeric controls in My flow. Your selection is saved and applied when you start the flow. Sunset cutouts now follow the same waves as the foreground. Main navigation uses a consistent icon family; Local library is renamed PC library. Playlists are collapsed by default with the same section-heading style as My music. Russian, English and all four themes remain supported.
