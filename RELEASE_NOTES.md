## Orbita 1.7.0 — автоматические обновления

- Установка в профиль текущего пользователя без прав администратора.
- Проверка и загрузка стабильных обновлений в фоне, без прерывания музыки.
- Установка при полном выходе через трей или по кнопке «Перезапустить и установить».
- Раздел обновлений в настройках: текущая версия, ручная проверка, загрузка и переключатель автоматического режима.
- Прежний профиль, подключение к Звуку, библиотека, очередь и темы сохраняются.
- Закат с волнами и четыре цветовые темы из 1.6.1 сохранены.

Для первого перехода с архивной версии один раз установи этот EXE вручную, предварительно завершив Orbita через трей. Дальнейшие версии будут приходить в приложение.

Установщик пока без сертификата Authenticode. Это не запрос прав администратора; ограничения корпоративной политики по запуску программ могут действовать отдельно.
