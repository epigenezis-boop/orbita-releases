# Orbita — выпуски для Windows

Orbita: Плеер мечты, объединяющий стриминговые подписки и локальные библиотеки. Сейчас встроено подключение стриминга СберЗвук.

## Установка

Скачай **Orbita-Setup-…-x64.exe** в [последнем выпуске](https://github.com/epigenezis-boop/orbita-releases/releases/latest), полностью закрой прежнюю Orbita через трей → **Выйти**, затем запусти установщик.

Установка выполняется для текущего пользователя, без запроса прав администратора. Профиль прежней Orbita `%APPDATA%\volna-player` сохраняется. Повторно входить в Звук не требуется.

## Обновления

После первого перехода на установщик Orbita проверяет обновления в фоне и загружает стабильные выпуски. Музыка не прерывается. Загруженное обновление устанавливается при выборе **Выйти** в трее. В настройках можно проверить обновления вручную, отключить автоматическую загрузку или выбрать **Перезапустить и установить**.

Здесь нет персональных токенов, cookies или пользовательской библиотеки. Приложению не нужен аккаунт GitHub для получения выпусков.

## Выпуск новой версии

В репозитории находятся служебные файлы сборки и архив исполняемого пакета Electron, а не пользовательский профиль. Как и любой пакет Electron, исполняемый архив содержит JavaScript приложения. Публикация запускается после обновления `release.json` в `main`. GitHub Actions проверяет SHA-256 пакета, запускает тесты, собирает установщик Windows и проверяет, что манифесты установщика и программы запрашивают `asInvoker` (без повышения прав). Выпуск становится публичным после загрузки установщика, blockmap и `latest.yml`.

Стабильную опубликованную версию не заменяем: для исправлений повышаем номер. Сбой загрузки оставляет выпуск черновиком. Токен публикации — временный `GITHUB_TOKEN` в Actions; в приложение он не включается.
